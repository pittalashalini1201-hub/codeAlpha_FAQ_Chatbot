# AI FAQ Chatbot

A simple AI FAQ Chatbot built using Flask and Natural Language Processing (NLP). The chatbot answers frequently asked AI-related questions by finding the most similar question using TF-IDF and cosine similarity.

## Features

* Answers AI-related FAQs
* Uses TF-IDF vectorization
* Uses cosine similarity for matching questions
* Simple and user-friendly web interface
* Built with Flask

## Technologies Used

* Python
* Flask
* Scikit-learn
* HTML
* CSS

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   python3 app.py

3. Open in your browser:
   http://127.0.0.1:5000

## Example Questions

* What is artificial intelligence?
* What is machine learning?
* What is Python?
* What is NLP?
